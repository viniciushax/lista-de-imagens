# 🖼️ Lista de Imagens Responsiva - HTML + CSS

Este projeto consiste em uma **galeria/lista de imagens responsiva**, criada com **HTML e CSS puro**, com base em um layout desenvolvido no **Figma**. A proposta foi montar uma interface que funcione bem tanto em **telas grandes (desktop)** quanto em **dispositivos móveis**, mantendo a estética limpa e a boa usabilidade.

## 🎨 Design

O design da interface foi elaborado no [Figma](https://www.figma.com), com foco em apresentar imagens de forma organizada, adaptável e visualmente agradável. O layout inclui espaçamentos, grid responsivo e estilo coeso para diferentes tamanhos de tela.

## 🛠 Tecnologias Utilizadas

- HTML5
- CSS3
- Figma (para prototipação)

## 🧩 Funcionalidades

- Layout com display flex para exibição das imagens
- Adaptação automática da grade com media queries
- Estilo responsivo para desktop e mobile
- Comportamento fluido ao redimensionar a tela
- Estrutura semântica e leve

## 💡 Aprendizados

Durante o projeto, pratiquei e aprofundei conceitos como:
- **CSS Flexbox**
- **Media queries para responsividade**
- Conversão de layout do **Figma para código real**
- Organização de conteúdo visual
